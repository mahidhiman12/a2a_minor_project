# ComplaintCard
One complaint as a grouped-list row: icon, the citizen's words, ID and departments, status and time.

**Consumer provides.** A `unified` status object. Shows the first department's icon, `summary` (one line, `callout`), `complaint_id` in `mono` with location and departments (`footnote`), `overall_status` as a StatusBadge and relative `updated_at`. Rows share one inset list; hairlines start after the icon. Click opens the detail; hover tints the row.
