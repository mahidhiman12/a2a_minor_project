# TextField
A labelled input on `bg-subtle` that turns white with a blue border when focused.

**Consumer provides.** `label` (always visible, 13px `ink-secondary`), `placeholder` in the citizen's voice, optional leading `icon`, `helper`, `error`.

**Style.** 48px, `radius-md`, no border at rest; hover deepens to `fill`. Focus: `surface`, 1px `focus` border, 3px soft halo. Error: `red` border and `red-ink` helper with the message — never colour alone. `pill` variant for search and track-by-ID. IDs use `mono`.
