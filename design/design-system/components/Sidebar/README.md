# Sidebar
A macOS-style source list on `bg-subtle`, 240px wide.

**Consumer provides.** Items (icon, label, optional count), the active route, and the department group built from discovered Agent Cards. Active item: `fill` background, icon turns `ink`. Group headers are 11px semibold `ink-tertiary`. Footer shows agent health as a status dot. Collapses to a 64px icon rail under 1100px; a sheet on phones.
